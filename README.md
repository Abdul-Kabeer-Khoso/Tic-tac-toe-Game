# Tic-Tac-Toe

A classic two-player game of Tic-Tac-Toe.

## How to Play

1.  Run the game.
2.  Two players take turns marking spaces on a 3x3 grid.
3.  Player 1 is usually 'X', and Player 2 is 'O'.
4.  The first player to get three of their marks in a row (horizontally, vertically, or diagonally) wins.
5.  If all nine squares are filled and no player has three in a row, the game is a draw.

## How to Run
1. Clone the repository
2. Run this index.html file in any code editor
